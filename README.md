# 🎬 Film Flicks
**Interactive Film-Themed Quiz & Ticket Booking Web Application**

## 📖 Description
**Film Flicks** is an interactive, film-themed web application developed as a **college mini project during the 5th semester (3rd Year)**.  
The application allows users to explore movies, participate in engaging quizzes, book movie tickets, and earn **real-time discounts** based on their quiz performance.
The project focuses on **user engagement, logical flow, and dynamic content handling**, combining entertainment with practical implementation of core web development concepts.

## 🛠 Tech Stack
- **HTML5** – Structure and layout  
- **CSS3** – Styling and responsive UI  
- **JavaScript** – Application logic & interactivity  
- **MySQL** – Movie data and quiz questions (backend logic)  
- **JSON** – Dynamic movie and quiz data handling  

## ✨ Features
- 🎥 Movie showcase with images and trailers  
- 🧠 Interactive movie-based quiz system  
- 🔐 User login flow simulation  
- 📊 Real-time quiz scoring system  
- 🎟 Movie ticket booking functionality  
- 💰 **20% discount** on tickets for users scoring **8/10 or above**  
- 🔊 Audio feedback for booking and discount status  
- 📱 Responsive design for multiple screen sizes  

## 🚀 Getting Started
To run this project locally:
1. Clone the repository  
```bash
git clone https://github.com/akshaykumar112151/Film-Flicks.git
```
2. Open the project folder
```bash
cd Film-Flicks
```
3. Open index.html in your browser
```bash
start index.html
```
